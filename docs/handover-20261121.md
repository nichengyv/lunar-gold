## 8. 踩坑

1. **PowerShell 5**：不能用 `&&` / `||`，用 `;`；`-Dtest=A,B` 必须加引号。
2. **`.ps1` 编码**：UTF-8 带 BOM，否则中文乱码或脚本被破坏。
3. **新增 `@PublicApi` 端点**：必须同步 `PublicApiCatalog.DECLARED` + 契约快照，否则启动自检失败；已有漂移测试守卫。
4. **增量编译会漏错**：新符号/新 import 用 `mvn clean test` 验证。
5. **前端 build**：沙箱下把 `TEMP`/`TMP` 指向 `frontend/node_modules/.cache/esbuild-tmp`。
6. **git 锁残留**：报 `index.lock` 时先确认无 git 进程，再删除 `.git/index.lock`。
7. **进程内测试与真实进程不同**：续跑语义必须用 `scripts/resume-e2e.ps1` 验证，不要只靠单测。
8. **`JavacDiagnosticsProviderTest.validJavaHasNoErrors` 会偶发失败**：进程内 javac 有 15s 超时，机器高负载（IDE 语言服务器等）时 `available=false`；单独跑或重跑通常通过，不要据此改产品代码。
