## 需求覆盖

- [x] 阶段时间线包含理解、读取、修改、验证、汇总五步，并标注当前步骤与每步耗时。
- [x] 阶段只前进不后退；未到达的中间阶段显示「跳过」，不伪造耗时。
- [x] 预算行同时展示轮次、token、已用时间，并对照各自上限。
- [x] 上限为 0 时显示「不限」；旧后端缺字段时降级为「—」，不报错。
- [x] 任一预算 ≥80% 有警示；达到上限时展示明确原因与建议。
- [x] 失败分为可重试、需配置、需审批、需人工四类，标签/提示/主操作各不相同。

- [x] 停止后「继续」可用，发出固定续写提示并开始新一轮。
- [x] 时间预算默认 0（不限），开启后超限停止并给出原因。
